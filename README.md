# Écran de la maison

Tableau de bord pour l’iPad de l’entrée : heure, météo, agenda, courses, tâches, budget et plat du soir.

- `index.html` et `app.js` : l’app (GitHub Pages).
- `data.json` : agenda et plat du jour, mis à jour chaque jour par une tâche programmée.
- Les listes partagées sont dans Firebase Realtime Database, sous `foyers/<code>`.
